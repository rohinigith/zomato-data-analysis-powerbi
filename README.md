# Zomato Data Analysis Power BI Dashboard

An interactive **Microsoft Power BI dashboard for Zomato data analysis**, designed to explore restaurant and food-delivery data through interactive visualizations, filters, and business insights.

## Dashboard

The complete Power BI report is provided in:

`Zomato.pbix`

The PBIX file contains the complete report, visuals, data model, measures, filters, and report configuration.

## Analysis Areas

- Restaurant and business information
- Location and geographic analysis
- Ratings and customer-related metrics
- Pricing and cost analysis
- Online ordering / delivery information
- Cuisine and category analysis

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

## How to Open

1. Download `Zomato.pbix`.
2. Install Microsoft Power BI Desktop.
3. Open the PBIX file.
4. If prompted, configure the data-source credentials or paths.
5. Refresh the report if required.

> GitHub stores the PBIX file but does not render the interactive Power BI report directly. Open the file using Power BI Desktop.
