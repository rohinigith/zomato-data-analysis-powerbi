# Zomato Dashboard Overview

This repository contains the Power BI report for the Zomato data-analysis project.

The main source file is `Zomato-Data-Analysis-Dashboard.pbix`. It contains the complete report, data model, visuals, measures, filters, and configuration.

The project transforms Zomato-related data into interactive business-intelligence views covering restaurant information, location, ratings, pricing, cuisines/categories, and ordering/delivery attributes.

Add dashboard screenshots to `docs/assets/` if you want them displayed in the GitHub README.
